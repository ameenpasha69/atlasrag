# AtlasRAG

Hybrid lexical + dense retrieval with Reciprocal Rank Fusion, verifiable citations,
and mandatory abstention.

Status, verified capabilities and known limitations live in [STATUS.md](STATUS.md).
Nothing in this repository is described as working unless a command in
[EVIDENCE.md](EVIDENCE.md) produced that result.

See also [DECISIONS.md](DECISIONS.md), [EVALUATION.md](EVALUATION.md), [SECURITY.md](SECURITY.md).
