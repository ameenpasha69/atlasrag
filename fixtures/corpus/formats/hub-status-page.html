Hub Status Reference

Each hub reports a status colour every sixty seconds. The colour is derived from the exception lane depth and the oldest unprocessed item age, whichever is worse.

Status colours

Green means the exception lane holds fewer than twenty items and nothing has waited more than ten minutes. Amber means either threshold has been crossed. Red means both have been crossed, or the hub has not reported for three consecutive intervals.

A hub that reports red for more than fifteen minutes escalates automatically to the regional duty manager. Escalation is recorded with the reference HUB-ESC-2291.

Reporting gaps

A missing report is not treated as red immediately, because a single dropped interval is usually a network blip. Three consecutive misses are treated as red because that pattern has never been observed without an underlying fault.
