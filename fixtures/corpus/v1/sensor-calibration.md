# Conveyor Sensor Calibration

Every sorting line carries an optical gap sensor mounted above the belt. The reference unit
used for calibration across all three hubs is stamped with the serial CAL-X7-4421B and is
stored in the Pune metrology cabinet.

## Procedure

Calibration runs at the start of each quarter. The technician mounts the reference unit
beside the installed sensor, runs 500 test items across the belt, and records the difference
in reported gap width. A deviation above 1.5 millimetres requires the installed sensor to be
replaced rather than adjusted.

Adjustment is only permitted within a deviation band of 0.4 to 1.5 millimetres. Below 0.4
millimetres the sensor is considered within tolerance and is left untouched, because repeated
adjustment shortens the life of the mounting bracket.

## Records

Each calibration produces a record containing the reference serial, the installed sensor
serial, the measured deviation, the technician identifier, and the timestamp. Records are
kept in the metrology register, which is separate from the operational log stores described
in the retention policy.
